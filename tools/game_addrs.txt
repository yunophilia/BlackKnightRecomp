# USA release (RENE8P). tools/game_addrs.py finds each one in the other releases and
# writes runtime/game_addrs.inc; refer to them by name, never by number.
#
#   NAME  KIND  RENE8P-ADDRESS  [description]
#
# KIND: func  function start, overridden in the runtime (PPC_OVERRIDE(NAME)) or called;
#             its code must be the same in every release
#       code  instruction (recompiler patches and probes); must be the same instruction
#       data  variable in main.dol's data or bss
